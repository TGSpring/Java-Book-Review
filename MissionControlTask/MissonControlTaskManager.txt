This project must ONLY use concepts from Chapter 10.

You are expected to design the program yourself rather than following a
step-by-step tutorial. The purpose is to practice problem solving, software
design, and object-oriented programming using ArrayLists.

If you ask ChatGPT for help, treat it as a professor during office hours.

ChatGPT should:
    • Explain concepts
    • Answer questions
    • Review code
    • Point out mistakes
    • Give hints
    • Ask guiding questions

ChatGPT should NOT:
    • Write entire methods
    • Design classes for you
    • Solve the assignment unless specifically requested after a genuine
      attempt

The objective is learning, not simply finishing the project.

===============================================================================
                                PROJECT
===============================================================================

Mission Control manages maintenance tasks aboard a space station.

Astronauts submit work requests throughout the day. Mission Control stores,
tracks, organizes, and updates these tasks.

Your program should allow a user to manage this task list from a console menu.

Every task will be stored inside an ArrayList.

===============================================================================
                            PROGRAM REQUIREMENTS
===============================================================================

Your program should be capable of:

    • Adding new tasks
    • Displaying every task
    • Searching for a task
    • Marking a task as complete
    • Removing tasks
    • Sorting tasks
    • Displaying useful statistics
    • Running continuously until the user chooses Exit

===============================================================================
                              CLASS DESIGN
===============================================================================

You are responsible for designing your own classes.

Think carefully about:

    • What classes are needed?
    • What data belongs in each class?
    • Which fields should be private?
    • Which methods belong in each class?
    • Which class should own the ArrayList?

Do not immediately begin coding.

Spend time designing first.

===============================================================================
                               TASK OBJECT
===============================================================================

Create a class representing a single mission task.

Decide what information each task should store.

Possible ideas include:

    • Task name
    • Assigned astronaut
    • Priority
    • Estimated completion time
    • Completion status

These are suggestions.

If you wish to add another field that still fits Chapter 10,
you may do so.

Your task class should also provide behavior appropriate for a task.

Examples might include:

    • Mark complete
    • Display task information
    • Update priority

Decide which behaviors make sense.

===============================================================================
                           MISSION CONTROL
===============================================================================

Create another class responsible for managing every task.

This class should own an ArrayList of your task objects.

It should provide functionality for:

    • Adding tasks
    • Removing tasks
    • Finding tasks
    • Displaying tasks
    • Displaying completed tasks
    • Sorting tasks
    • Computing statistics

Think about:

    Should each method print information?

or

    Should it return information?

Choose whichever design makes the most sense.

===============================================================================
                             DRIVER PROGRAM
===============================================================================

Create a menu-driven console application.

The menu should repeatedly prompt the user until Exit is selected.

Example layout:

    ===============================
       MISSION CONTROL
    ===============================

    1. Add Task
    2. Display Tasks
    3. Search Task
    4. Complete Task
    5. Remove Task
    6. Sort Tasks
    7. Statistics
    8. Exit

Your exact menu design is up to you.

===============================================================================
                               COMPARABLE
===============================================================================

MissionTask must implement Comparable.

You must decide:

    What makes one task come before another?

Examples might include:

    • Priority
    • Estimated completion time
    • Task name

If two tasks are equal according to your primary comparison,
decide how ties should be broken.

Be prepared to explain your design choice.
